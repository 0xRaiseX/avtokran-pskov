# Автокран Псков — лендинг

Одностраничный сайт услуги аренды автокрана. Статика: HTML + CSS + немного JS,
без сборки и зависимостей. Достаточно открыть `index.html` или залить папку на любой хостинг.

## Что поменять перед запуском

### 1. Контакты — `js/config.js`

Единственный файл с контактными данными. Отредактируйте значения:

| Поле | Что это |
|---|---|
| `phoneDisplay` | номер в том виде, как он показывается на сайте |
| `phoneRaw` | номер для ссылки «Позвонить», только `+` и цифры |
| `messenger` | куда ведёт кнопка «Написать»: `whatsapp`, `telegram`, `vk`, `max`, `sms`. **Пустая строка — кнопки «Написать» исчезают со всей страницы, остаётся только «Позвонить»** |
| `vk` | ссылка на страницу или сообщения ВКонтакте |
| `whatsapp` | номер для WhatsApp, только цифры без `+` |
| `telegram` | имя пользователя без `@` |
| `max` | полная ссылка на профиль MAX |
| `messageText` | текст, подставляемый в сообщение |
| `workHours` | режим работы, сейчас «Работаем без выходных» |
| `businessName` | название в подвале |
| `ownerName` | имя владельца в подвале; сюда же дописать ИП/ООО и ИНН, когда появятся |

Номер и часы работы подставляются во все места на странице автоматически.

### 2. Фотографии — папка `img/`

Сейчас стоят реальные снимки:

| Файл | Место в галерее | Что на фото |
|---|---|---|
| `img/hero.jpg` | первый экран | кран на кладке стен из газоблоков |
| `img/works/work-01.jpg` | узкая вертикальная | бадья с бетоном на крюке |
| `img/works/work-02.jpg` | широкая в первом ряду | погрузка комбайна на трал |
| `img/works/work-03.jpg` | узкая вертикальная | монтаж силоса |
| `img/works/work-04.jpg` | половина ряда | работа у производственного корпуса |
| `img/works/work-05.jpg` | половина ряда | подъём на высоту у жилого дома |
| `img/works/work-06.jpg` | половина ряда | разгрузка пиломатериалов |
| `img/works/work-07.jpg` | половина ряда | фундамент из блоков ФБС |
| `img/works/work-08.jpg` | панорама на всю ширину | автокран КАМАЗ |

Плитки обрезают фото по своему размеру (`object-fit: cover`), поэтому подойдут
снимки любых пропорций. Вертикальные снимки ставьте на позиции 1 и 3,
горизонтальные — на остальные, панорамные лучше всего смотрятся на позиции 8.

Чтобы добавить плитку, скопируйте блок `<figure class="shot">` в `index.html`
и допишите в `css/styles.css` правило `.shot:nth-child(9)` по образцу соседних.

Рекомендуемый размер — от 1500 px по длинной стороне, JPEG. `alt` пишите по делу:
что на фото и где («Разгрузка плит на объекте в Пскове») — это влияет на поиск.

### 3. Мелочи

- `img/og-cover.png` — превью для мессенджеров и соцсетей. Сейчас это скриншот
  первого экрана; при желании замените на фото техники 1200×630.
- **После покупки домена** раскомментируйте два тега в начале `index.html`
  (`canonical` и `og:url`) и подставьте адрес. Без них сайт работает,
  но превью ссылки в мессенджерах будет беднее.
- `img/favicon.svg` — иконка вкладки.

## Структура

```
index.html                разметка страницы
css/styles.css            все стили
js/config.js              контакты (правится заказчиком)
js/main.js                подстановка контактов, галерея, анимации
img/                      фотографии
```

## Проверено

- мобильная вёрстка от 320 px, горизонтального скролла нет;
- кнопки «Позвонить» / «Написать» — на первом экране, в финальном блоке,
  в шапке и в закреплённой нижней панели на телефоне;
- без JavaScript весь текст остаётся видимым;
- анимации отключаются при системной настройке «уменьшить движение».

## Отзывы

Шесть отзывов в блоке «Отзывы заказчиков» перенесены с Avito дословно, правились
только явные опечатки и обрезанные окончания фраз. Рядом стоит ссылка на объявление,
чтобы отзывы можно было проверить — без неё они выглядят как самописные.

Сетка блока рассчитана на число отзывов, кратное трём: при шести получается два
ровных ряда. Если добавите седьмой — последний ряд станет неполным, лучше сразу
доводить до девяти.

Чтобы добавить новый, скопируйте блок `<li class="review">` в `index.html`.
Ничего не выдумывайте: неправдивый отзыв — это и репутация, и статья закона о рекламе.

## Цены

Цена указана в блоке «Стоимость»: наличными от 2500 ₽ в час, дорога считается
по пробегу, выезд до 300 км. Если ставка изменится — правится в `index.html`
в секции `#price` и в чипе на первом экране.

## Чего на сайте намеренно нет

Минимального заказа по часам и реквизитов ИП — эти данные не подтверждены,
а выдумывать их для коммерческого сайта нельзя.

На шести фотографиях были водяные знаки Avito — они убраны кадрированием.
